# D3.16 — Native Deku bubble model

## Implementation
- Replaced the temporary `gEffFire1DL` stand-in with the original OoT bubble display list `gBubbleDL` (segment 6, offset `0x1000`).
- Changed the actor profile object dependency from `OBJECT_GAMEPLAY_KEEP` to `OBJECT_BUBBLE`, so the actor requests the object that owns the display list.
- Kept the projectile's existing charge-derived scale and applied billboard orientation for the translucent bubble presentation. The bubble rotates slowly using its own remaining lifetime (`99 - timer`) as a local frame counter, avoiding a dependency on a `GameState.frames` field that is not present in this OoTMM build.
- The OoT object manifest already registers `object_bubble.xml`, including `gBubbleTex` and `gBubbleDL`; no duplicate asset import was added.

## Validation boundary
This change is source-integrated. CI typecheck/C compilation and tests are the automated validation gate. A generated ROM and in-game rendering/collision test have not been performed, so visual scale and texture appearance remain subject to runtime verification.
