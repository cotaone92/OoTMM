# D3.20 — Deku bubble flight drift

## Implementation
- Added a deterministic side-to-side yaw drift during flight using the OoT sine-table helper.
- Added gradual horizontal deceleration, with a minimum speed of 4.0 units, so the bubble does not retain arrow-like constant velocity for its full lifetime.
- Preserved the existing gentle upward velocity, gravity, geometry rebounds, shield reflection, lifetime and collision registration.
- The drift is deterministic and uses the existing lifetime counter; no new persistent state or save data is introduced.

## Reference and adaptation
Majora's Mask's Deku bubble uses a changing flight direction and adjusts projectile speed as its bubble state changes. This step adapts that floaty behavior to the current OoT actor without importing MM-only audio or actor dependencies.

## Validation boundary
CI checks source compilation/typecheck and automated tests. The sway amplitude, deceleration curve, collider feel and interactions with enemies/shields still require a generated ROM and gameplay test; those have not yet been performed.
