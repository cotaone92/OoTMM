# D3.7 — Importación del paquete de animaciones Deku

## Alcance
Se registran las 19 animaciones de jugador Deku declaradas en el `gameplay_keep.xml` de Majora's Mask para que OoTMM las importe desde la ROM MM al paquete de animaciones cruzadas y las exponga mediante `COMBO_IMPORTED_LINK_ANIMATION_LIST_OOT`.

## Animaciones registradas
Headers `gPlayerAnim_pn_*` en `objects/gameplay_keep`, offsets `0xE268` a `0xE2F8`:
Tbox_open, attack, batabata, doorA_open, doorB_open, drink, drinkend, drinkstart, gakkiplay, gakkistart, getA, getB, gurd, kakku, kakkufinish, maskoffstart, rakkafinish, tamahaki y tamahakidf.

Estos son offsets de headers, no offsets de frames.

## Resolución y validación
- `frame_data_offset` es opcional. Si falta, el builder resuelve el offset real desde el puntero segmentado del header.
- El builder exige que los frames originales estén en el segmento `0x07` de `link_animetion`.
- Cada frame usa 22 entradas `Vec3s` (raíz más articulaciones), con tamaño `22 * 6 + 2 = 0x86` bytes.
- Se mantienen las comprobaciones de límites, frame count y tamaño declarado.

## Integración
El generador crea los headers importados y `animations.c` los registra en la lista destinada a OoT. Las animaciones quedan disponibles como símbolos C en el build generado.
