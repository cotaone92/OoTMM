# D3.3 — Deku model object import

## Status

Implemented in the development branch as a source-level change. This is not yet a compiled ROM or a runtime-tested model.

## Changes

- `ObjectEditor` now has a LOD skeleton import path:
  - `processSkeletonLodLimbAddr` relocates both near and far display-list pointers in a 16-byte LOD limb.
  - `processSkeletonLodLimbsAddr` relocates the LOD limb pointer array.
  - `processFlexSkeletonLodHeaderAddr` relocates the limb array referenced by a FlexSkeletonHeader while preserving the remaining header fields.
- `CustomObjectsBuilder` now imports Majora's Mask `objects/object_link_nuts` as custom object `DEKU_LINK`.
- The importer starts from `gLinkDekuSkel` at segment address `0x0600ba24`. The XML source declares the skeleton as Flex + LOD and lists the limb entries beginning at object offset `0xB880`.

## Runtime contract

The generated custom object ID and its generated offset macro must be consumed from the generated `combo/custom.h`; do not hardcode a numeric custom-object ID or assume the skeleton's packed output address. The first generated offset for `DEKU_LINK` is the relocated skeleton header because it is submitted first.

The runtime loader must resolve the custom object through OoT's extended object-slot mechanism and set segment 6 to that loaded object before drawing. It must not retain a raw object pointer or slot across object-context resets.

## Validation still required

1. Run the generator/type checks to confirm the TypeScript changes compile.
2. Inspect the generated `CUSTOM_OBJECT_ID_DEKU_LINK` and `CUSTOM_OBJECT_DEKU_LINK_0` definitions.
3. Confirm both near/far display lists and their transitive vertices/textures were relocated into the output object.
4. Build an OoT ROM and test object loading and skeleton drawing in-game.
5. Add the Deku-specific draw callback and bypass human boots/gauntlets after the model import is proven.

No ROM, save, or user-supplied source ROM was modified. No compilation or emulator test has been performed by this change.
