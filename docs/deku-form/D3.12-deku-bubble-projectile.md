# D3.12 — Deku bubble projectile foundation

## Implemented source foundation
- Reserved OoT custom actor ID `ACTOR_CUSTOM_DEKU_BUBBLE` at unused slot `0x073`.
- Added a dedicated OoT actor overlay, separate from `En_Arrow`, so ordinary bow and slingshot projectiles are not modified.
- The actor has its own cylinder attack collider, finite lifetime, forward movement, wall/floor/ceiling termination, and translucent cyan rendering using an existing OoT effect display list as a temporary visual stand-in.
- The actor uses `OBJECT_GAMEPLAY_KEEP`; it does not require a new object slot at this stage.

## Not yet connected
- Player input/charge state and the MM `pn_tamahaki` / `pn_tamahakidf` animation tracks.
- Magic meter validation and consumption.
- Spawn origin/rotation from Deku Link.
- Exact MM bubble mesh, growth curve, bounce rules, impact effects, and sound.
- Typecheck, C compile, overlay registration validation, ROM build, and in-game projectile tests.

## Safety boundary
This actor does not replace or patch OoT `En_Arrow`. Normal arrows and slingshot projectiles remain on their original paths. The current visual is explicitly temporary and the actor is not yet spawned by player input.
