# D3.22 — Deku bubble: swept surface collision

## Goal

Reduce the chance that the Deku bubble passes through thin level geometry between background checks.

## Implementation

- Preserve the frame's starting position and calculate the intended end position using the existing `Actor_MoveXZGravity` movement.
- Test four evenly spaced positions along that movement segment with the engine background check for walls, floor, and ceiling.
- Keep the last position that passed the background check.
- If a surface is detected, restore the bubble to that last clear position and apply the existing bounded rebound behavior.
- Preserve the existing rebound limit, horizontal speed reduction, vertical floor/ceiling response, lifetime, and collision registration.

## Scope and limitations

This is a discrete four-slice sweep using the existing actor background-check API, not a mathematical continuous raycast. It improves detection granularity without introducing unverified collision APIs. The slice count and collision dimensions still require ROM/in-game tuning.

## Validation
